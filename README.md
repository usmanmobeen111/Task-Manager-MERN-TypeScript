# 🚀 Taskify - Modern Task Management System

![Taskify Banner](https://images.unsplash.com/photo-1484480974693-6ca0a78fb36b?q=80&w=2072&auto=format&fit=crop)

Taskify is a premium, full-stack task management application built with the **MERN** stack (MongoDB, Express, React, Node.js) and powered by **TypeScript**. It features a stunning user interface with smooth animations, glassmorphism effects, and real-time filtering to keep your productivity at its peak.

## ✨ Features

- **Full CRUD Operations**: Create, Read, Update, and Delete tasks effortlessly.
- **Dynamic Filtering**: Filter tasks by status (All, Pending, In Progress, Completed) with instant UI updates.
- **Premium UI/UX**: Designed with a focus on aesthetics using **Tailwind CSS** and **Framer Motion**.
- **Responsive Design**: Seamlessly manage your tasks on mobile, tablet, or desktop.
- **Rich Task Details**: Categorize tasks with tags, priority levels, and deadlines.
- **Animated Interactions**: Smooth transitions and entrance animations for a high-end feel.

## 🛠️ Tech Stack

### Frontend
- **React 19** with **TypeScript**
- **Tailwind CSS** for modern styling
- **Framer Motion** for premium animations
- **React Icons** for intuitive visuals
- **Axios** for API communication

### Backend
- **Node.js** & **Express**
- **MongoDB** with **Mongoose**
- **TypeScript** for end-to-end type safety
- **Dotenv** for secure environment management

## 🚀 Getting Started

### Prerequisites
- Node.js installed
- MongoDB database (Local or Atlas)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/usmanmobeen111/Task-Manager-MERN-TypeScript.git
   cd Task-Manager-MERN-TypeScript
   ```

2. **Backend Setup**
   ```bash
   cd server
   npm install
   # Create a .env file and add your MONGODB_URI and PORT
   npm run dev
   ```

3. **Frontend Setup**
   ```bash
   cd ../client
   npm install
   # Create a .env file and add VITE_API_URL
   npm run dev
   ```
